# Calmon

Free during beta. A scrolling tiling window manager for macOS 26 or later. Calmon is not open source.

## Install

Beta · [Release notes](RELEASE_NOTES.md)

Download [calmon-beta.20261110.1.dmg](https://github.com/cxa/calmon/releases/download/vbeta.20261110.1/calmon-beta.20261110.1.dmg) (SHA-256: `92f3ce624b30b179ac4d7cda67e539be14590828348f5ce2efc3cd73e5df7c0b`). Move Calmon to Applications, open it, and follow Getting Started to allow Accessibility access. Check for Updates in the menu bar keeps direct downloads current.

```sh
brew tap cxa/calmon https://github.com/cxa/calmon.git
brew install --cask cxa/calmon/calmon
```

[Website and demo](https://lazyapps.com/calmon/) · [Help and feedback](https://github.com/cxa/calmon/issues)
