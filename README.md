# Calmon

Free during beta. A scrolling tiling window manager for macOS 26 or later. Calmon is not open source.

## Install

Beta · [Release notes](RELEASE_NOTES.md)

Download [calmon-beta.20261109.0.dmg](https://github.com/cxa/calmon/releases/download/vbeta.20261109.0/calmon-beta.20261109.0.dmg) (SHA-256: `9aafe2f55fe33a04539fca770020aefcf607c289e0e02f7d67830e0e965d069c`). Move Calmon to Applications, open it, and follow Getting Started to allow Accessibility access. Check for Updates in the menu bar keeps direct downloads current.

```sh
brew tap cxa/calmon https://github.com/cxa/calmon.git
brew install --cask cxa/calmon/calmon
```

[Website and demo](https://lazyapps.com/calmon/en/) · [Help and feedback](https://github.com/cxa/calmon/issues)
