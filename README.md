# Calmon

Free during beta. A scrolling tiling window manager for macOS 26 or later. Calmon is not open source.

## Install

Beta · [Release notes](RELEASE_NOTES.md)

Download [calmon-beta.20261105.0.dmg](https://github.com/cxa/calmon/releases/download/vbeta.20261105.0/calmon-beta.20261105.0.dmg) (SHA-256: `f9eafd89ce538439af15bd84ba07493362d2b23e8f87af1a325daaafc87402ae`). Move Calmon to Applications, open it, and follow Getting Started to allow Accessibility access. Check for Updates in the menu bar keeps direct downloads current.

```sh
brew tap cxa/calmon https://github.com/cxa/calmon.git
brew install --cask cxa/calmon/calmon
```

[Website and demo](https://lazyapps.com/calmon/en/) · [Help and feedback](https://github.com/cxa/calmon/issues)
