# Calmon

Free during beta. A scrolling tiling window manager for macOS 26 or later. Calmon is not open source.

## Install

Beta · [Release notes](RELEASE_NOTES.md)

Download [calmon-beta.20261107.0.dmg](https://github.com/cxa/calmon/releases/download/vbeta.20261107.0/calmon-beta.20261107.0.dmg) (SHA-256: `d5d4c2e4586aa82474170998e20a6eabd5780ab7f165b1f85f3eb208d4d9ecdf`). Move Calmon to Applications, open it, and follow Getting Started to allow Accessibility access. Check for Updates in the menu bar keeps direct downloads current.

```sh
brew tap cxa/calmon https://github.com/cxa/calmon.git
brew install --cask cxa/calmon/calmon
```

[Website and demo](https://lazyapps.com/calmon/en/) · [Help and feedback](https://github.com/cxa/calmon/issues)
